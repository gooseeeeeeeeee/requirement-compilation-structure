# Development and version control

This fork is maintained for the user's agent experiments.

- Develop on `codex/agent-improvements`.
- `origin` is `https://github.com/gooseeeeeeeeee/requirement-compilation-structure.git`.
- `upstream` is `https://github.com/code-philia/requirement-compilation-structure.git`.
- The user authorizes committing and pushing completed agent changes to the
  development branch. Validate meaningful changes and use descriptive commits.
- Keep main as the upstream reference unless the user requests a merge.
- Preserve existing history; do not force-push or push to upstream.
- Stage only intended source, tests, and documentation. Never commit credentials,
  local environment files, dependencies, generated applications, or raw run logs.
- State the resulting commit and relevant validation in the response.
